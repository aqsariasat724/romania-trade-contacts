# Romania Trade Contacts — data sample

Automated collection sample of Romanian trade businesses across five sectors:
design offices & architects, locksmithing & metalwork, electrical installations,
stonemasonry and carpentry.

- `index.html` — sample preview with measured field coverage
- `sample.csv` — 24 rows, three columns (Company Name, Phone, Email)

## Source and licence

Base records (company name, phone, website) are derived from OpenStreetMap —
© OpenStreetMap contributors, licensed under the
[Open Database Licence (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/).
A database derived from ODbL data carries attribution and share-alike obligations.

Email addresses are not from the base records: each was read from the company's
own public website or contact page.

Addresses belonging to a named individual are removed; only role and company
addresses are included.
